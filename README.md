## Overview

UZDoom Mod Manager is a desktop tool for organizing Doom mod WAD files and launching them through UZDoom or GZDoom with complex load order arguments. It manages mod collections, auto-generates launch arguments, remembers per-mod configuration presets, and simplifies the otherwise command-line-heavy process of running large Doom mod compilations.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **UZDoom Mod Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **WAD Collection** | Organize WAD, PK3, and DEH mod files into named collections |
| **Load Order** | Drag-and-drop load order control generates correct -file arguments |
| **Per-Mod Config** | Save and recall UZDoom/GZDoom configuration presets per mod |
| **One-Click Launch** | Launch any saved collection directly from the manager interface |
